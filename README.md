
## Code explanation:
The code contains a recreation of the snake game, where the objective is for the snake to reach the green apple as much as possible whilst avoiding collisions of the boundaries of the game window and the snake's own growing body. 

It has a menu which explains the game and allows the player to quit the game. During gameplay there is a point counter in the top left of the screen which increments by 100 for every gained apple. When the snake collides with itself or with the game's window borders, a game over screen will be shown for 2 seconds, where the final score is gained, and then is reset once returning back to the main menu. Clicking exit closes the game.


## Packages to install:
- pygame
- pygame-menu
  
```pip install pygame pygame-menu```


## Setup Instructions:
1. Run pip install pygame, pygame-menu to install necessary packages
2. Run the file


## Controls:
- **W: Up**
- **A: Left**
- **S: Down**
- **D: Right**
